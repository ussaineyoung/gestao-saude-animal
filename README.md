# Gestão de Saúde Animal

Sistema em Java para gestão de saúde animal, desenvolvido no NetBeans com Maven.

## Funcionalidades
- Registo de animais
- Registo de consultas e tratamentos


## Tecnologias
- Java
- Maven
- NetBeans

## Como executar
1. Clonar o repositório
2. Abrir o projecto no NetBeans
3. Executar a classe `Gestaosaudeanimal`
