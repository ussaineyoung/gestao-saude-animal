# Gestão de Saúde Animal

Sistema em Java para gestão de saúde animal, com interface gráfica, desenvolvido no NetBeans com Maven.

## Funcionalidades
- Gestão de animais
- Registo de informação de saúde
- Painel de alertas

## Estrutura do projecto
- `modelo`: classes do sistema (ex.: Animal)
- `dados`: acesso e formatação de dados (Repositorio, Formatos)
- `ui`: interface gráfica (PainelAnimais, PainelSaude, PainelAlertas)
- `Main.java`: ponto de entrada

## Tecnologias
- Java
- Maven
- NetBeans

## Como executar
1. Clonar o repositório
2. Abrir o projecto no NetBeans
3. Executar a classe `Main`
